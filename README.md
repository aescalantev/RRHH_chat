Alura
Repositorio para incorporar desarrollos correspondientes a los cursos de Alura Usmito es el asistente virtual del área de RRHH de Excelence Desarrollo de Software: un chatbot con RAG (Retrieval-Augmented Generation) que responde preguntas relacionadas a las políticas de RRHH de la empresa.

Características principales: • Carga de las políticas de RRHH ubicada en tres documentos PDF. • Realización de preguntas por empleados de la empresa. • Respuesta a las preguntas realizadas por los empleados.

Tecnologías utilizadas: • Backend: Python, LangChain, Google Gemini. • Frontend: HTML, CSS y JavaScript (pendiente). • Control de versiones: Git y GitHub.

Repositorio: [https://github.com/aescalantev/RRHH_chat.git]
